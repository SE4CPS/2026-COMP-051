# COMP-051 — Fall 2026 Course Code

Starter code and class materials for COMP-051 (Introduction to Programming
in C++), University of the Pacific, Fall 2026.

## Contents

- `final-project/` — the Final Project starter code (a console-based
  record-management app using classes, inheritance, polymorphism,
  vectors, and file streams). See `final-project/README.md` for the
  assignment brief and `final-project/starter/` for the code itself.

## Getting the code

```
git clone https://github.com/SE4CPS/2026-COMP-051.git
```

See the slide deck (linked from Canvas) for build instructions and a
walkthrough of how the starter code works.
