# COMP-051 — Fall 2026 Course Code

Starter code and class materials for COMP-051 (Introduction to Programming
in C++), University of the Pacific, Fall 2026.

## Contents

- `gridrunner.cpp` — the GridRunner semester project, as one single file
  at the root of the repo. Drive a car from a random start to a random
  destination with the arrow keys; it uses every module of the course
  (variables, branches, loops, vectors, functions, classes, inheritance,
  polymorphism, and exceptions). Windows only (uses `conio.h` and
  `windows.h`); build it in Visual Studio.
- `GridRunner-Poster.pdf` — the example project poster: module map with
  real code statistics, screenshots of the game running, and highlighted
  code samples.
- `final-project/` — the Final Project starter code (a console-based
  record-management app using classes, inheritance, polymorphism,
  vectors, and file streams). See `final-project/README.md` for the
  assignment brief and `final-project/starter/` for the code itself.
