# Practice Lab: Stockton Weather

A real JSON file, 31 days of synthetic Stockton, CA weather data
for July 2026 (made up for this lab, not real recorded weather).
Each line is one day: `date`, `high`, `low`, `condition`.

See comp-051 Module 9's "Practice Lab Part 3" for the full
walkthrough: a `WeatherDay` struct, a small `field()`/`parseLine()`
parser (no external JSON library needed), and 10 questions to
answer from the data (hottest day, coldest night, average
temperatures, how many Sunny days, and more).
